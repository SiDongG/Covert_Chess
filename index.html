Covert communication in LLM-agent conversations.
No shared model. No shared prompt.

Two agents embed and recover a hidden message through ordinary dialogue — the receiver sees only the text, with no access to the other agent's model, prompt, or token probabilities. The transcript stays provably indistinguishable from a normal conversation.

the gap

Hiding a message in AI text isn't new. Doing it with no shared model or prompt is.

Prior methods work — but only if the two agents share a model, a prompt, and a stream of randomness as long as the message. Take those crutches away — so the receiver sees only the generated text, with nothing about the sender's model (the black-box setting) — and almost nothing survives on real conversation. That's the gap we close.

prior work

Shared-model, fixed-length

  • Needs a shared model and prompt
  • Needs synchronized randomness that grows with the message
  • Fixed codeword length — breaks when a turn ends early or runs long
  • Too many errors on low-entropy chat
this work

No sharing, adaptive

  • Prompt- and model-agnostic — the decoder only reads text
  • Side info from a shared seed, not a length-scaled key stream iOne 128-bit seed + a fresh per-session nonce, expanded on demand via HMAC-SHA-256.
  • Variable-length — adapts to however the turn unfolds
  • Reliable even when each word carries almost no entropy

the setting, precisely

Token generation is a channel with feedback

Normally the model just samples the next token from its distribution. The sender instead biases which token gets chosen, so it carries a symbol of the message; the receiver recovers that symbol from the text and a shared seed alone. Write the message as \( m \in \{0,1\}^{\ell} \) — the decoder is a function \( g(X, \kappa)\to\hat m \) of the transcript and seed that never touches the model.

The fact everything rests on: both agents see each token the instant it appears. The sender always knows exactly what the receiver knows — a channel with causal, noiseless feedback, and feedback is the lever we pull for reliability.

challenges & fixes

Four obstacles, four fixes

Operating with no shared model or prompt — the receiver reads only text — creates specific problems. Here is each one, and the mechanism that resolves it.

Challenge 01 — the decoder can't see the model

Recover the symbol from text alone

With no access to token probabilities, the receiver needs to read back what was sent using only the words and the shared seed.

the fix — geometry on a circle

Following ArcMarkiArcMark: tokens and symbols placed on a unit circle, sampling biased by angular distance., every token and every message symbol sits on a unit circle. Sampling nudges the text toward the token whose angle is nearest the target; the receiver re-derives that angle \( \hat{C}_t \) from the token and seed — no model in the loop.

Challenge 02 — conversation is low-entropy

Spread the message across many tokens

Most words in a chat have one obvious continuation, so any single token can carry almost nothing. Push too hard and the text turns unnatural.

the fix — posterior matching

Rather than loading bits onto individual tokens, the sender exploits the feedback: at each step it picks the next symbol from the decoder's current belief, steering that belief to concentrate on the true message across many low-entropy tokens.

the belief update
\( \pi_t(m) \;\propto\; \pi_{t-1}(m)\,\cdot\,\ell_t(m) \)

belief in message m after this token = belief before × how well the token fits m

Challenge 03 — variable-length turns, and confident-but-wrong guesses

Feedback coding: the Yamamoto–Itoh decode-and-confirm scheme

A fixed codeword can't match a turn that ends early or runs long — and even a confident guess can be wrong. The answer is to use the feedback channel as a code, not just a belief tracker.

the fix — a two-phase feedback code

Posterior matching localizes the message; then a Yamamoto–Itoh confirmation phase re-transmits a single ACK/NACK bit to verify it before committing. The stopping time is variable — the protocol ends the moment it's sure — and that dedicated confirmation phase is exactly what buys the optimal reliability exponentiThe Burnashev exponent — the best possible error decay for a feedback channel.. Together they form the feedback code we call BAM.

Where the reliability gain comes from
Noiseless feedback can't raise capacity, but it sharply improves the error exponent. Two effects combine: sequentiality (a variable stopping time — spend more tokens only while uncertain) and adaptivity (choose each symbol from past observations). The two-phase structure follows Yamamoto–Itoh, and the exponent it targets is Burnashev-optimal. Full statement and proof are in the paper.
Challenge 04 — it has to stay undetectable

Change the meaning, not the statistics

Biasing the text toward a message must leave no statistical trace a monitor could learn to catch.

the fix — distortion-free coupling

An optimal-transport couplingiSolved via Sinkhorn; exact base marginal, so KL divergence is zero in the sense of Cachin. picks the biased token while holding the observable distribution exactly equal to the base model's. A nonce-separated pseudorandom function supplies the per-token side information, making the whole transcript computationally indistinguishable from clean generation.

why it's undetectable
\( \sum_{k} P(k)\, W(x \mid u,k,s) \;=\; W(x \mid s) \)

averaged over the secret key, the text has exactly the base model's word statistics

The upshot: no test on the visible text does better than a coin flip. The formal indistinguishability guarantee and its proof are in the paper.

security

Undetectable — and provably so

Each token is drawn while holding the visible distribution equal to the base model's, so the conversation carries no statistical signature — which is why the trained detector above sits at chance. Beyond that empirical test, the transcript is computationally indistinguishable from ordinary generation to any efficient adversary.

The formal statement and its proof are in the paper.

what this means

Watching the words isn't enough

We build this to make a blind spot concrete: if coordinating agents want a channel hidden in plain conversation, transcript monitoring alone won't find it — the visible text is provably ordinary. Defenses have to look elsewhere: at the generation process, at the entropy available to agents, at the coordination itself rather than the payload. We regard that as the central open problem this work raises.
